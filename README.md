# UNVERIFIED

A first-person psychological horror game about room inspection and anomaly detection.

Built with Unity 6 (HDRP). Solo project.

**Play for free (Windows):** [itch.io link]

*Inspection. Anomaly. Trust No One.*

## Premise

You are hired by Mr. Voss to inspect rooms in a Victorian house.

For each room, you decide: is everything normal, or is something wrong? If something is wrong, you must also report what kind of anomaly it is.

Mr. Voss briefs you before every inspection, but his briefings are not always accurate.

## Features

- 9 rooms to inspect, each randomly generated as normal or anomalous
- Five anomaly types to report: Missing, Extra, Position, Rotation, Scale
- An unreliable narrator whose briefings may be misleading
- A flashlight with a limited battery; find spare batteries hidden in drawers
- Three different endings

## Controls

| Key | Action |
|-----|--------|
| W A S D | Move |
| Mouse | Look around |
| F | Toggle flashlight |
| Mouse wheel | Adjust flashlight beam angle |
| E | Interact (drawers, batteries) |
| Tab | Open report panel |
